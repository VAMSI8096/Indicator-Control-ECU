# Indicator Control ECU

## Overview
This project implements an automotive indicator control system using embedded C.

## Features
- Left Indicator
- Right Indicator
- Hazard Mode
- Debounce Logic
- UART Logging

## Hardware Used
- Arduino UNO
- Push Buttons
- LEDs

## How to Run
1. Connect the circuit
2. Upload code to microcontroller
3. Open Serial Monitor
